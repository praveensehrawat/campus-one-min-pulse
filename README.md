📌 Campus One-Minute Pulse

Only what matters today. Nothing extra.

Campus One-Minute Pulse is a lightweight student dashboard that shows daily-critical campus information in under one minute — notices, emails, mess updates, campus status, and emergency access — all in one place.

🎯 Problem Statement

Students receive important information through long emails, scattered notices, and multiple platforms. This often leads to missed deadlines, confusion, and information overload.

Campus One-Minute Pulse simplifies this by showing only what a student needs to act on today.

💡 Solution Overview

The dashboard compresses essential campus information into a single, distraction-free interface with:

Priority-based notices

Smart email action summaries

Personalized mess insights

Live campus status

Emergency quick access

The goal is clarity, speed, and actionability.

⚙️ How It Works

Detects date and weekday on load

Displays dynamic mess menu

Analyzes notices and emails using keyword-based logic

Assigns priority and extracts actions

Personalizes dashboard based on student type

Updates mess and campus insights dynamically
